# References

[![banner](/.internals/trademarks/banner_1200x100.svg)](#)

Below are the references used in this project repository:

> [!NOTE]
>
> * Format:
>   * `[FIRST_NAME]`, `[LAST_NAME]`; `[LAST_NAME]`, `[FIRST_NAME]`;
>     `[DISPLAY_NAME]`; ...more_authors separated by semicolon;
>     `[COPYRIGHT_YEAR_EARLIEST]`; "`[TITLE_HERE]`"; *`[CATEGORIES_HERE]`*;
>     DOI: `[DOI_ID]`; SKU: `[SKU_ID]`; UUID: `[UUID]`; Series: `[SERIES_ID]`;
>     Volumes: `[VOLUME_ID]`; ...more_ids separated by semicolons;
>     `[PLATFORM_NAME]` (`[BRAND]`) via `PUBLISHER_NAME` (`GOV_ID`);
>     `[LOCATION_STATE_NAME]`, `[COUNTRY_FULL_NAME]`; Viewed: `[YYYY-MM-DD]`;
>     Available at: `[SOURCE_URL]` (Private URL)
>     * For publication with no `[PLATFORM_NAME]` (`[BRAND]`) fields like
>       an ancient hardcopy script, they can be omitted and only use
>       `PUBLISHER_NAME` (`GOV_ID`) instead.
> * List is from the **EARLIEST** -> **LATEST** using numeric (`1.`, `2.`, ...)
>   numbering system.
> * Once reference number is assigned, it **MUST NOT** be changed to avoid
>   breaking the entire repository.
